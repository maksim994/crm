# Работа с лидами

Как искать, просматривать и обрабатывать лиды в админке Lead CRM.

---

## Где находятся лиды

Меню **Лиды** (`/admin/` → **Лиды**) — все лиды по всем заказчикам.

Также можно открыть лиды:

- с карточки **Заказчика** → кнопка **Лиды заказчика**;
- с карточки **Проекта** — счётчик лидов и ссылка в контексте проекта.

Заказчик в [личном кабинете](/cabinet/) видит **только свои** лиды — без служебных полей менеджера.

---

## Список и фильтры

| Фильтр | Зачем |
|--------|--------|
| **Заказчик** | Ограничить список одним клиентом |
| **Проект** | Лиды конкретного сайта (доступен после выбора заказчика) |
| **Статус** | Этап обработки менеджером |

Нажмите **Обновить**, чтобы перезагрузить список.

### Колонки таблицы

| Колонка | Что показывает |
|---------|----------------|
| **Дата** | Когда лид попал в CRM |
| **Заказчик / Проект** | К кому относится обращение |
| **Телефон** | Основной контакт |
| **Тип** | Способ поступления: заявка, звонок, почта, вручную |
| **Канал** | Источник трафика: реклама, поиск или «нет данных» |
| **Статус** | Этап работы менеджера |

Подробнее про «Тип» и «Канал»: [Яндекс.Метрика](metrika-dlya-menedzhera.md).

## Карточка лида

Откройте лид из списка → **Открыть**.

### Блок «Контекст»

- **Заказчик** и **Проект** — привязка лида
- **Канал** (в карточке) — тип поступления (заявка / звонок / почта)
- **Статус** — этап обработки
- **Реклама** — источник трафика для отчётов

### Блок «Контакт»

Телефон, email, имя и комментарий посетителя — как пришло с формы, из письма или звонка.

### Блок «UTM и Метрика»

Метки с посадочной страницы и Client ID Метрики. Нужны для атрибуции «Реклама» в ЛК.

---

## Статусы обработки

Менеджер меняет статус на карточке → **Редактировать**.

| Статус | Когда ставить |
|--------|----------------|
| **Лид не обработан** | Новый лид, ещё не взяли в работу |
| **Не ответили на звонок** | Пытались дозвониться — без ответа |
| **Составляем КП** | Готовится коммерческое предложение |
| **Клиент неинтересен** | Обращение нецелевое |
| **Сделка провалена** | Работа завершена без сделки |

Статус виден и в админке, и в личном кабинете заказчика.

---

## Редактирование служебных полей

На странице **Редактирование лида** доступны:

| Поле | Назначение |
|------|------------|
| **Статус** | Этап обработки (см. выше) |
| **Менеджер** | Кто ведёт лид |
| **Комментарий** | Внутренняя заметка для команды |

Эти поля **не передаются с сайта** и **не редактируются** заказчиком в ЛК.

---

## Добавить лид вручную

Кнопка **Добавить лид** на странице списка.

Когда это нужно:

- заявка пришла по телефону или мессенджеру, минуя сайт;
- нужно восстановить обращение, которое не попало в CRM автоматически.

Заполните:

1. **Проект** — обязательно
2. **Телефон или email** — хотя бы одно поле
3. Имя, описание, комментарий — по ситуации
4. UTM и Client ID — если знаете (можно оставить пустыми)

Лид создаётся с типом **Вручную**.

---

## Дубликаты

CRM автоматически помечает повторное обращение, если на том же проекте за последние **30 дней** уже был лид с тем же телефоном или email.

Это служебный флаг для менеджера — лид всё равно сохраняется.

---

## Что видит заказчик

В личном кабинете клиент видит:

- дату, проект, контакты, UTM, тип и рекламный канал;
- статус обработки.

Клиент **не видит**: комментарии менеджера, внутренние поля ACC/PPC, IP и другую служебную информацию.

Подробнее: [Личный кабинет заказчика](lichnyj-kabinet.md).
