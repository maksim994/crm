# Настройка проекта

Проект в Lead CRM — это конкретный сайт или посадочная, с которой принимаются лиды. Здесь — все поля карточки и когда их менять.

Первичное создание: [С чего начать](nachalo-raboty.md).

---

## Где редактировать

**Проекты** → выберите проект → **Редактировать**  
или **Заказчики** → карточка заказчика → список проектов.

---

## Основные поля

| Поле | Обязательно | Зачем |
|------|-------------|--------|
| **Заказчик** | да | К какому клиенту относится сайт |
| **Название проекта** | да | Как проект отображается в списках и в ЛК |
| **Домены** | да | Домены сайта — по одному в строке, без `https://` |
| **Метрика ID** | нет | Номер счётчика Яндекс.Метрики на сайте |
| **Ключевые слова бренда** | нет | Для отчётов бренд / небренд в ЛК |
| **Timezone** | нет | Часовой пояс проекта (по умолчанию Москва) |
| **Статус** | да | Принимает ли проект новые лиды |

---

## Статусы проекта

| Статус | Поведение |
|--------|-----------|
| **Активен** | Новые лиды принимаются |
| **Приостановлен** | Новые лиды **не** принимаются (интеграции вернут ошибку) |
| **В архиве** | Проект снят с работы, лиды не принимаются |

Если лиды перестали приходить — первым делом проверьте, что статус **Активен**.

---

## Токен интеграции

Токен нужен для подключения форм, звонков и скрипта подстановки почт.

- После создания проекта CRM **один раз** показывает токен — скопируйте сразу.
- На карточке проекта: блок **Токен интеграции** (можно скопировать).
- **Перевыпустить токен** — если старый утёк; прежний токен перестанет работать на всех интеграциях.

Токен передаётся разработчику сайта — не публикуйте его в открытом коде страницы.

---

## Почты проекта

Три поля для подмены email на сайте по источнику трафика:

| Поле в админке | Когда показывается на сайте |
|----------------|----------------------------|
| **Почта (реклама)** | Переход из рекламы |
| **Почта (SEO / поиск)** | Переход из поисковиков |
| **Почта (прямые заходы)** | Прямой заход на сайт |

На каждый из этих ящиков настройте **пересылку** на `mail@crm-lead.ru`.

Подробнее: [Интеграция почты](integraciya-pochty.md).

---

## Блок интеграции на карточке

На странице проекта отображаются:

- URL для приёма заявок с формы;
- URL для webhook звонков;
- HTML-код скрипта подстановки почт;
- пример тестовой отправки.

Передайте эти данные разработчику или используйте при самостоятельной настройке — см. [Интеграция форм](integraciya-form.md).

---

## Проверка проекта

Внизу карточки проекта — блок **Проверка проекта**.

| Проверка | Что означает для менеджера |
|----------|----------------------------|
| Токен задан | Можно подключать интеграции |
| Почты заполнены | Готово к приёму писем и подмене на сайте |
| Счётчик Метрики указан | Можно уточнять источник трафика |
| Доступ к Метрике | Платформа может читать статистику счётчика |

Нажмите **Обновить**, чтобы перезапустить проверку.

Общая диагностика платформы — меню **Диагностика** в админке (для внутреннего контроля, не для заказчика).

---

## Типичные ошибки

| Ситуация | Решение |
|----------|---------|
| Лиды не приходят | Статус проекта → **Активен** |
| Форма перестала работать после смены токена | Обновите токен в `lead.php` на сайте |
| Письма не привязываются к проекту | Адреса в полях почты совпадают с теми, куда пишут клиенты |
| В ЛК пустая «Реклама» | Заполните **Метрика ID**, проверьте UTM на форме — см. [Яндекс.Метрика](metrika-dlya-menedzhera.md) |
