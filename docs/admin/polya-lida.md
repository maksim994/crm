# Поля лида при приёме заявки

Справочник: **какие поля можно передать** при создании лида извне (форма, звонок, почта) и **что CRM заполняет сама**.

Отдельно в админке менеджер может дополнять служебные поля (статус обработки, комментарии ACC/PPC) — они **не** принимаются с сайта.

---

## Общие правила

| Правило | Описание |
|---------|----------|
| Привязка к проекту | Лид всегда создаётся на **проект**, определяемый по **токену** |
| Контакт | Обязателен **телефон и/или email** (хотя бы одно поле) |
| Канал | Тип поступления (`form`, `call`, `email`, `manual`) CRM ставит **сама** по endpoint |
| Дубликаты | Флаг `is_duplicate` CRM вычисляет **сама** (тот же телефон/email на проекте за 30 дней) |
| Реклама | Поле «Реклама» сначала из UTM, затем может обновиться из Метрики (если включено) |

Подробнее о каналах: [Интеграция форм](integraciya-form.md), [Интеграция почты](integraciya-pochty.md).

## 1. Заявка с формы сайта

**Endpoint:** `GET` или `POST` `/ingest/seolead`  
**Метод передачи:** query string, `application/x-www-form-urlencoded` или JSON.

### Поля, которые можно передать

| Параметр запроса | В CRM (поле лида) | Обяз. | Описание |
|------------------|-------------------|-------|----------|
| `token` | — | **да** | Токен проекта из админки (`uuid:secret`) |
| `phone` | Телефон | да* | Номер телефона |
| `email` | Email | да* | Email посетителя |
| `name` | Имя | нет | Имя из формы |
| `description` | Описание формы | нет | Текст кнопки, название формы, тема заявки |
| `product` | Запрос на продукт | нет | Что выбрал посетитель |
| `comment` | Комментарий | нет | Свободный текст посетителя |
| `metrika_client_id` | Client ID Метрики | нет | `yaCounter.getClientID()` |
| `page_url` | Домен посадочной | нет | URL страницы отправки; домен сохранится в **Домен посадочной** |
| `utm_source` | utm_source | нет | UTM из URL или hidden-полей |
| `utm_medium` | utm_medium | нет | |
| `utm_campaign` | utm_campaign | нет | |
| `utm_term` | utm_term | нет | |
| `utm_content` | utm_content | нет | |
| `utm_campaign_first` | utm_campaign_first | нет | Первая кампания в цепочке (если есть) |
| `ip` | IP посетителя | нет | Реальный IP, если знает прокси (`lead.php`) |

\* Обязателен **хотя бы один** из `phone` или `email`.

### Что CRM заполняет сама

| Поле в CRM | Как появляется |
|------------|----------------|
| **Канал** | `Заявка` (form) |
| **Домен посадочной** | Из `page_url` (host) |
| **Реклама** | По UTM; позже — из Метрики (Reporting API) |
| **IP посетителя** | IP запроса или параметр `ip` |
| **Дубликат** | Поиск по телефону/email за 30 дней на этом проекте |
| **Дата создания** | Момент приёма |
| **raw_payload** | Полный входящий запрос (служебно) |

### UTM из `page_url`

Если UTM не переданы отдельными полями, CRM попробует взять их из query string в `page_url`.  
Также распознаются `yclid`, `gclid` и аналоги → подставляются `utm_source` / `utm_medium`.

### Ответ API

- JSON: `{ "id": "uuid-лида" }` — код **201**
- Plain text: только `uuid` — если заголовок `Accept: text/plain`

`id` нужен для отправки в Метрику: `yaCounter.params({ 'crm-lead': id })`.

### Пример

```bash
curl -X POST "https://lk.crm-lead.ru/ingest/seolead" \
  -d "token=ВАШ_ТОКЕН" \
  -d "phone=+79001234567" \
  -d "description=Заявка с главной" \
  -d "page_url=https://example.ru/?utm_source=yandex&utm_medium=cpc" \
  -d "metrika_client_id=17791064241773632"
```

## 2. Звонок (коллтрекинг)

**Endpoint:** `POST /api/v1/leads/call`  
**Токен:** query `?token=...` или заголовок `X-Site-Token`  
**Формат:** JSON или form (Callibri и совместимые).

| Параметр | В CRM | Обяз. | Описание |
|----------|-------|-------|----------|
| `phone` | Телефон | **да** | Номер звонящего |
| `created_at` | Дата лида | нет | Время звонка (если не указано — сейчас) |
| `metrika_client_id` | Client ID Метрики | нет | |
| `utm_source` … `utm_content` | UTM | нет | |
| `call_recording_url` | Запись разговора | нет | Ссылка на аудио |
| `call_duration_sec` | Длительность, сек | нет | |

**Канал в CRM:** `Звонок`.

## 3. Письмо (inbound email)

Лид создаётся из текста письма — **отдельные поля формы не передаются**.

| Источник | Что извлекается |
|----------|------------------|
| Тело + тема письма | Телефон и/или email (regex) |
| Отправитель | Email, если валидный |
| Текст | **Описание формы** (тема + тело, до 5000 символов) |

**Канал в CRM:** `Почта`.  
**Реклама:** «Нет данных», если не обогащено вручную.

Способы подключения: [Интеграция почты](integraciya-pochty.md).

## 4. Ручное создание в админке

**Раздел:** **Лиды** → **Создать лид**

| Поле формы | В CRM | Обяз. |
|------------|-------|-------|
| Проект | site_id | **да** |
| Телефон / Email | phone / email | да* |
| Имя | contact_name | нет |
| Описание | form_description | нет |
| Комментарий | comment | нет |
| Запрос на продукт | product_request | нет |
| Client ID Метрики | metrika_client_id | нет |
| UTM (все) | utm_* | нет |

**Канал в CRM:** `Ручной ввод`.

---

## 5. Поля только в CRM (не с сайта)

Эти поля **нельзя записать** через `/ingest/seolead` или webhook. Их заполняют менеджеры в админке или они появятся в будущих интеграциях:

| Группа | Примеры полей |
|--------|----------------|
| Обработка | Статус лида, менеджер |
| Квалификация | ИНН, город, SKU, ожидаемая сумма |
| ACC / PPC | Статусы и комментарии отделов |
| Служебные | `raw_payload`, внутренние ID |
