# Если что-то не работает

Краткий справочник для менеджера: что проверить, если интеграция или данные ведут себя не так, как ожидается.

---

## Лид не появился в CRM

### Заявка с формы сайта

| Шаг | Проверка |
|-----|----------|
| 1 | Проект в статусе **Активен** — см. [Настройка проекта](nastrojka-proekta.md) |
| 2 | Токен в `lead.php` на сайте совпадает с токеном в карточке проекта |
| 3 | Отправьте тестовую заявку с сайта и подождите несколько секунд |
| 4 | **Лиды** → фильтр по заказчику и проекту |

Подробнее: [Интеграция форм](integraciya-form.md).

### Письмо

| Шаг | Проверка |
|-----|----------|
| 1 | Копия письма дошла до `mail@crm-lead.ru` |
| 2 | На почте проекта настроена пересылка на служебный ящик |
| 3 | В CRM на проекте указан тот же адрес, на который писал клиент |
| 4 | Подождите до **5 минут** (CRM опрашивает ящик по расписанию) |

Подробнее: [Интеграция почты](integraciya-pochty.md).

### Звонок (коллтрекинг)

| Шаг | Проверка |
|-----|----------|
| 1 | Проект **Активен** |
| 2 | В настройках коллтрекинга указан URL webhook и токен с карточки проекта |
| 3 | Тестовый звонок → лид с типом **Звонок** в CRM |

## Лид есть, но поля пустые или неверные

| Симптом | Что проверить |
|---------|----------------|
| Нет телефона / email | В форме или письме должен быть распознаваемый контакт |
| «Реклама» = «Нет данных» | UTM не переданы или прямой заход; для уточнения — [Яндекс.Метрика](metrika-dlya-menedzhera.md) |
| Неверный проект | Для форм и звонков — токен; для почты — адрес ящика в настройках проекта |
| UTM пустые | Проверьте, что форма передаёт метки из URL посадочной |

Справочник полей: [Поля лида](polya-lida.md).

---

## Метрика

| Симптом | Что проверить |
|---------|----------------|
| В Метрике нет `crm-lead` | На сайте после отправки формы должен вызываться код передачи ID лида — см. [Интеграция форм](integraciya-form.md) |
| «Реклама» не совпадает с Метрикой | ID счётчика на проекте = счётчик на сайте; отправьте тест с UTM `utm_medium=cpc` |
| Пустая аналитика в ЛК | Заполнен **Метрика ID** на проекте; на сайте установлен тот же счётчик |

## Личный кабинет

| Симптом | Что проверить |
|---------|----------------|
| Клиент не может войти | Email и пароль из блока **Доступ в личный кабинет**; галочка **Доступ активен** |
| Не видит нужный проект | В доступе включено «Все проекты» или отмечен конкретный проект |
| Не видит новый проект | Если доступ выборочный — добавьте проект в список доступных |
| Пустой список лидов | Лиды есть в админке по этому проекту; у пользователя ЛК есть доступ к проекту |

Подробнее: [Личный кабинет заказчика](lichnyj-kabinet.md).

## Подмена почты на сайте

| Симптом | Что проверить |
|---------|----------------|
| На сайте один и тот же email | Подключён скрипт с карточки проекта; заполнены три поля почты |
| Подмена не меняется при переходе с рекламы | Откройте сайт с `?utm_medium=cpc` в новой вкладке |
| Письмо пришло, лида нет | Пересылка с проектного ящика на `mail@crm-lead.ru` |

---

## Когда передать техническому специалисту

Обратитесь к администратору платформы, если:

- в **Диагностика** красным отмечены инфраструктура, почта или очередь;
- после всех проверок выше проблема повторяется;
- нужно изменить настройки сервера или почтового ящика CRM.
