# С чего начать

Краткий порядок первой настройки в **Lead CRM**: заказчик → проект → доступ в личный кабинет → интеграция сайта.

---

## Как устроены данные

```text
Заказчик (клиент агентства)
  └── Проект (сайт / лендинг)
        └── Лиды
```

- **Заказчик** — юрлицо или бренд, для которого ведёте лиды.
- **Проект** — конкретный сайт или посадочная. У каждого проекта свой **токен** для приёма заявок.
- **Пользователь ЛК** — учётная запись заказчика для просмотра лидов в [личном кабинете](/cabinet/).

---

## Шаг 1. Добавить заказчика

1. Войдите в админку: `/admin/`
2. Меню **Заказчики** → **+** или кнопка **Новый заказчик**
3. Заполните форму:

| Поле | Обязательно | Зачем |
|------|-------------|--------|
| **Название** | да | Как заказчик отображается в списках |
| **ИНН** | нет | Для идентификации в CRM |
| **Контакт** | нет | Имя ответственного со стороны клиента |
| **Email / Телефон** | нет | Контакты для внутренней работы (не для входа в ЛК) |
| **Комментарий** | нет | Заметки менеджера |
| **Статус** | да | **Активен** — работаем; **В архиве** — скрыт из активной работы |

4. Нажмите **Сохранить**.

После сохранения откроется карточка заказчика — оттуда удобно добавлять проекты и доступы в ЛК.

---

## Шаг 2. Добавить проект

Проект = сайт, с которого будут приходить заявки.

### Создание

1. **Заказчики** → откройте нужного заказчика → **Добавить проект**  
   *(или **Проекты** → новый проект и выберите заказчика в форме)*
2. Заполните:

| Поле | Обязательно | Зачем |
|------|-------------|--------|
| **Заказчик** | да | К кому относится проект |
| **Название проекта** | да | Например «Сайт ruflex-pro.ru» |
| **Домены** | да | По одному в строке — для контроля посадочных |
| **Метрика ID** | нет | ID счётчика Яндекс.Метрики на сайте |
| **Статус** | да | **Активен** принимает лиды; **Пауза** и **Архив** — нет |
| **Ключевые слова бренда** | нет | Для отчётов бренд / небренд в ЛК |
| **Timezone** | нет | По умолчанию можно оставить `Europe/Moscow` |
| **Почты (реклама / SEO / прямые)** | нет | Если используете подстановку email на сайте |

3. **Сохранить**.

### Токен проекта

После создания CRM **один раз** покажет **токен интеграции** (`uuid:secret`). Скопируйте и сохраните — он нужен для форм на сайте.

- Токен всегда можно посмотреть на карточке проекта (**Проекты** → проект → **Токен интеграции**).
- Если токен утёк — **Перевыпустить токен** (старый перестанет работать).

Дальше настройте проект подробнее: [Настройка проекта](nastrojka-proekta.md), затем подключите сайт: [Интеграция форм](integraciya-form.md).

## Шаг 3. Создать учётную запись для личного кабинета

ЛК — отдельный вход для заказчика: `/cabinet/`. Это **не** email контактного лица из карточки заказчика.

1. **Заказчики** → карточка заказчика → блок **Доступ в личный кабинет** → **+ Добавить доступ**
2. Заполните:

| Поле | Обязательно | Зачем |
|------|-------------|--------|
| **Имя** | да | Отображается в интерфейсе ЛК |
| **Email для входа** | да | Логин в `/cabinet/` |
| **Пароль** | да (при создании) | Передайте клиенту безопасным каналом |
| **Все проекты заказчика** | — | Если включено — видны все текущие и будущие проекты |
| **Доступные проекты** | да* | Если «все проекты» выключено — отметьте нужные (*минимум один) |
| **Доступ активен** | — | Снимите галочку, чтобы заблокировать вход |

3. **Сохранить**. Пароль покажется один раз после создания — сохраните или сразу передайте клиенту.

### Проверка

- Клиент открывает `/cabinet/`, вводит email и пароль.
- Видит лиды только по выбранным проектам (или по всем, если включено «Все проекты заказчика»).

Подробнее о разделах ЛК: [Личный кабинет заказчика](lichnyj-kabinet.md).

## Быстрый чеклист «первый заказчик»

- [ ] Создан заказчик со статусом **Активен**
- [ ] Создан проект со статусом **Активен**, указаны домены
- [ ] Токен проекта скопирован
- [ ] Тестовая заявка с формы попала в **Лиды**
- [ ] Создан пользователь ЛК, клиент может войти в `/cabinet/`
