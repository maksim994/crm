# Яндекс.Метрика

Зачем нужна Метрика в Lead CRM и как проверить, что данные совпадают в админке и в личном кабинете заказчика.

---

## Зачем это менеджеру

Метрика помогает понять, **откуда пришёл лид**: из рекламы, из поиска или с прямого захода.

В CRM это отражается в двух разных полях — их часто путают:

| Поле в интерфейсе | Что означает | Примеры значений |
|-------------------|--------------|------------------|
| **Тип** (в списке лидов) | Как лид попал в CRM | Заявка, Звонок, Заявка на почту, Вручную |
| **Канал / Реклама** | Источник трафика на сайте | Переходы по рекламе, Переходы из поиска, Нет данных |

**Тип** CRM определяет сама по способу приёма (форма, звонок, почта).

**Реклама** — по UTM-меткам с формы и, при настроенной интеграции, по данным из Метрики.

---

## Что указать в проекте

На карточке **Проект** заполните:

| Поле | Зачем |
|------|--------|
| **Метрика ID** | Номер счётчика Яндекс.Метрики на сайте (тот же, что в коде сайта) |
| **Ключевые слова бренда** | Для отчётов «бренд / небренд» в личном кабинете |

Без ID счётчика CRM не сможет уточнить источник трафика через Метрику — останутся только UTM с формы.

Подробнее о полях проекта: [Настройка проекта](nastrojka-proekta.md).

---

## Параметр `crm-lead`

После успешной отправки формы сайт передаёт в Метрику ID созданного лида. Это **сквозная метка**: один и тот же визит на сайте связан с конкретной заявкой в CRM.

В отчёте Метрики **Параметры визита** появится:

```text
crm-lead → uuid лида из CRM
```

Это **не** тип заявки и не рекламный канал. Это связка «визит ↔ лид» для аналитики.

Настройка на стороне сайта описана в [Интеграция форм](integraciya-form.md) — блок «Метрика».

---

## Как заполняется «Реклама»

1. **Сразу при создании лида** — по UTM в URL посадочной (`utm_medium=cpc` → «Переходы по рекламе» и т.п.).
2. **Через некоторое время** — CRM может уточнить источник по данным Метрики (если на платформе включена интеграция с Reporting API).

Если UTM не переданы и Метрика не настроена, в колонке **Канал** будет **Нет данных** — это нормально для прямых заходов без меток.

---

## Чеклист проверки

1. На проекте указан **тот же ID счётчика**, что на сайте.
2. Отправьте тестовую заявку с рекламной меткой в URL, например:  
   `https://site.ru/?utm_source=yandex&utm_medium=cpc`
3. В админке → **Лиды** → откройте лид:
   - **Тип** = Заявка
   - **Реклама** = Переходы по рекламе (или уточнится позже)
4. В Метрике → **Параметры визита** → найдите `crm-lead` с ID этого лида.
5. В личном кабинете заказчик видит те же поля «Тип» и «Рекламный канал».

---

## Если «Реклама» = «Нет данных»

| Причина | Что сделать |
|---------|-------------|
| Заявка с прямого захода без UTM | Ожидаемо; можно проверить визит в Метрике |
| На форме не передаются UTM | Проверьте интеграцию формы — см. [Интеграция форм](integraciya-form.md) |
| ID счётчика не указан в проекте | Заполните **Метрика ID** на карточке проекта |
| Звонок или почта | Для этих типов «Реклама» обычно не заполняется |

Больше сценариев: [Если что-то не работает](chastye-problemy.md).

## Аналитика в личном кабинете

В ЛК у каждого проекта есть раздел **Аналитика** — графики трафика из Метрики (источники, поисковики, география, устройства).

Для работы раздела на проекте должен быть указан ID счётчика. Если графики пустые — проверьте счётчик на сайте и настройки проекта.

Подробнее: [Личный кабинет заказчика](lichnyj-kabinet.md).
