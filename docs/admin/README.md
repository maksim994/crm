# Документация для админки Lead CRM

Это **рабочая копия** документов, которые показываются в разделе «Документация» админ-панели (`/admin/docs/`).

| Папка | Назначение |
|-------|------------|
| `docs/admin/` | Редактируемая версия для пользователей админки |
| `docs/` (корень) | Техническая документация репозитория (README, этапы для разработки) |

При изменении текстов для админки правьте файлы **здесь**, в `docs/admin/`.  
Оригиналы в `docs/` можно оставить как справочник для команды разработки.

Структура и slug задаются в `config/documentation.php`.
